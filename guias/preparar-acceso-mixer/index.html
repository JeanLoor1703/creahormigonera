Guía / Entrega

Prepara el acceso del mixer

Antes de programar una entrega, revisa el recorrido hasta la obra y el espacio donde se recibirá el hormigón.

Consultar disponibilidad
Inicio / Guías / Acceso del mixer

El acceso influye en cómo se coordina la entrega. Compartir fotos y una referencia de ubicación puede ayudar al equipo a entender el sitio.

Lista de revisión

  • Ruta: portones, curvas, pendientes y tramos estrechos.
  • Terreno: confirma con el responsable de obra que el suelo y el espacio de maniobra sean adecuados.
  • Obstáculos: cables, ramas, estructuras o materiales que impidan el paso.
  • Punto de descarga: dónde se detendrá el mixer y cómo llegará el hormigón al elemento.
  • Personal y horario: prepara a quienes recibirán el material.

Si el acceso es complejo
